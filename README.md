SpendLess is a backend-driven money management and budgeting application that helps users track expenses, manage accounts, and control spending efficiently.
⸻
🚀 Features
	•	🔐 User Authentication (Signup / Signin)
	•	👤 User Management
	•	💸 Expense Tracking
	•	📊 Budget Management (planned)
	•	⚡ REST APIs with structured responses
	•	🛡️ Global Exception Handling
	•	📄 Swagger API Documentation
